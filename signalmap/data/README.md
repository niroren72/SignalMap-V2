# Data Directory

This directory holds local database files and GeoIP lookup databases.

## MaxMind GeoLite2 MMDB Files
For full GeoIP and ASN enrichment, place the following databases here:
- `GeoLite2-City.mmdb`
- `GeoLite2-ASN.mmdb`

You can obtain free GeoLite2 database files from [MaxMind](https://www.maxmind.com).
